# Ember Guard – BASS-II dataset & baseline model

## Files
- `data/bass2_appendixA_curated.psv` – one line per ISS test (122 tests), hand-transcribed from Appendix A (Tables A.1–A.6, report pp. 103–113). Readable and checkable line by line against the PDF.
- `data/bass2_dataset.csv` – generated by `code/build_dataset.py`: 340 rows, one per observed condition (O2 %, airflow, fuel) → `burning` or `extinction`, with `source` + `page` on every row.
- `data/bass2_seed.csv` – earlier 16 rows from the report text (pp. 13–28) and Link et al. 2018; kept for reference, not used by the model.
- `model/ember_guard_model.json` – coefficients + 300 bootstrap parameter sets (for the error band), valid ranges, validation scores. Easy to run in JavaScript in the demo.
- `model/validation_output.txt` – latest validation run.

## Columns (bass2_dataset.csv)
`test_id` (BASS-II test, e.g. B10), `pi`, `material`, `geometry`, `thickness_mm` (film/slab thickness or rod diameter), `width_cm`, `flow_config` (opposed/concurrent/stagnation), `o2_pct` (mean of calibrated initial and final O2), `o2_initial`, `o2_final`, `o2_flag`, `flow_cm_s`, `flow_quality`, `outcome`, `mechanism` (sustained / low_flow_or_oxygen_extinction / blowoff / no_sustained_ignition), `source`, `page`, `note`.

## Transcription rules (honest about uncertainty)
- Flow = the anemometer "air display" in cm/s. Below ~1 cm/s the anemometer reads 0; there the crew used the fan pot (≈0.3–0.5). Those steps are coded as 0.5 cm/s (burning plateau) and 0.4 cm/s (extinction), `flow_quality = below_sensor_floor`, consistent with Link et al. 2018 (flows down to 0.4 cm/s, no spread below ~0.6 cm/s).
- Blowoff flows given only as fan pot were estimated from pot↔air pairs in the same tables (pot 4.0 ≈ 11, pot 6.0 ≈ 13, pot 7.0 ≈ 15, max with 2 restrictors ≈ 22 cm/s) → `estimated_from_fan_pot`.
- "Flow turned off" = 0 cm/s.
- Feb 2014 tests read 22.2 % calibrated O2 in cabin air (raw 20.6 %); kept as published, flagged in `o2_flag`.
- Excluded: P21b, T23, T28a/b (hardware or ignition-technique failures, not fuel behaviour). Nomex (3 tests) and the wax candle (1) are in the dataset but not in the model (too few).
- All tests at ~1 atm in the MSG.

## Baseline model
Logistic regression (6 inputs): O2 %, log10(flow+0.1), its square (captures both "too little air" extinction and "too much wind" blowoff), and fuel family (thin film < 0.5 mm, thick slab, rod, fabric).
- Validation: GroupKFold(5) by **test**, 20 repeats – every test is predicted by a model that never saw any row of that test.
- Held-out AUC 0.79 ± 0.01, Brier 0.150 vs 0.191 no-skill baseline, balanced accuracy 0.61.
- Reads: more O2 → higher risk; risk peaks at moderate airflow (~3–10 cm/s) and drops at near-zero flow and at strong flow.

## Limits (say these in the demo)
- Estimates the risk that a flame could be sustained; it does not detect fires.
- Valid only inside the tested ranges: O2 ≈ 13.5–22 %, flow 0.4–47 cm/s, ~1 atm, these fuels (PMMA, SIBAL cotton-fiberglass). No CO2, humidity or temperature effect is learned from BASS-II.
- Small dataset (118 tests); extinction is rarer than burning; low-flow values are estimated; balanced accuracy is modest.
- No data on ignition sources; it says nothing about whether something will ignite.
